Demo code for 2026 robot (the final chassis, aka Indiana Skunk)

Uses one xbox controller on port 0.

Switch shooter between demo mode and regular mode with the use demo mode elastic toggle. When in demo mode, shooter pitch and velocity is controlled through "Demo Velocity Default Setpoint" and "Demo Pitch Default Setpoint" on elastic 

Control drive max velocity through "Drive Max Velocity" on elastic

Controls:
L Trigger: Index
R Trigger: Run Shooter

B: Reverse All
A: Intake (Also puts collector down)
Y: Pull intake up
